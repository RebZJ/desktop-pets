# Desktop workspace

Mode: Operate. Code-first app screen.

The confirmed brief uses warm paper, orange/red mascot accents and quiet, task-focused density. The desktop shell groups chat, writing, meetings, opt-in memory, extensions, models, settings and the sprite gallery. Actual native state owns capability claims. The original Pace sprite is the signature interaction.

Native desktop baseline: 1180x780, with an 800x560 minimum main window. The browser development layout also adapts to 390x844; it is not a separate mobile release. The pet, writing and speech windows follow the Tauri configuration.

Finish review evidence lives in `.impeccable/review/`: workspace pages, the three companion windows and compact layout captures. The independent review reached ship after the IME Enter, keyboard petting and one-use MCP confirmation fixes. Native runtime validation is tracked separately; these captures establish UI behavior and layout.

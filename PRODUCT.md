# Desktop Pets

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Confirmed execution brief: React and TypeScript inside a Tauri desktop app. A browser build supports development and automated tests; native capture and local inference belong to the desktop host.

## Users

People who want a playful desktop companion that can help with writing, conversations and meeting notes. The first release targets Apple Silicon Macs with 16 GB or more memory and macOS 15 or newer; cross-platform architecture is required. Conversation languages are English, Chinese, Japanese and Spanish.

## Product Purpose

Pace is a small animated companion that stays nearby and offers useful local assistance without requiring a cloud account. Success means the mascot feels alive, controls are understandable, and useful work has explicit, reviewable results.

## Capabilities and Constraints

The authorized implementation includes sprite actions, local chat and voice, a writing command bar with preview and explicit Apply, meeting transcription and speaker labels, opt-in application memory, explicit model downloads, local MCP extensions, pet packs, and settings. Native capabilities and model availability must be shown honestly. Never manufacture assistant messages, transcripts, meeting notes, installed models or capture results. Speaker labels are not automatically known real identities. Quick hide removes Pace and companion windows before screen sharing; there is no guarantee of screen-capture exclusion on macOS. Application memory is off by default. Browser pages are excluded from automatic memory collection in this release.

## Brand Commitments

Product name: Desktop Pets. Mascot name in this project: Pace. Reuse the existing yellow pixel cheetah with red headband and shoes, whose source project names it Velo. Preserve the existing twelve actions, artwork and timings. The approved execution brief calls for warm paper, orange/red brand accents, tasteful pixel details and quiet, task-focused density.

## Evidence on Hand

Twelve existing lossless WebP sprite strips and metadata from the user's Outpaced project, copied without pixel changes. No performance, audience, security audit or operating-system compatibility claims have been established by this UI work.

## Product Principles

- The companion is playful; the work interface is calm.
- Local actions explain their permissions and show real state.
- Generate a result for review before applying it elsewhere.
- A missing capability has a useful explanation and recovery action.
